## 一、APK 构建（已完成配置）

```bash
# H5 变更后需先同步：
cd vue3-h5 && sh ./build.sh VLStreamCloud && ./node_modules/.bin/cap sync android

# 出正式签名包：
cd Android/android && ./gradlew :app:assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

- `versionCode`（当前 1）每次提审 +1；`versionName`（当前 1.0.0）对用户展示
- `VL_ENV="single"` 已内置（build.gradle buildConfigField）
- ⚠️ **签名终身不可换**：`oortcloud.jks` 已写入 build.gradle，上架后严禁更换

## 二、华为 AppGallery 流程（首选市场）

1. [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) → 我的项目 → 创建应用

3. 需要：软著证书扫描件、App 备案号、隐私政策 URL、权限用途说明
