### 为什么剩下的步骤必须由你执行（精确技术原因）

本机 **没有 Apple Distribution 证书私钥**（钥匙串只有 2 个 `Apple Development: li li`）；
App Store 分发 profile（`iOS Team Store Provisioning Profile: com.oort.vlstream`，团队 CJ7Y2W2HT4，有效期至 2027-06-06）虽然在本机，但其绑定的分发证书指纹 `CB:72:63:7C:...` 在钥匙串里找不到对应私钥。
同时本机没有 ASC API key（`.p8`）、钥匙串无 Apple ID 凭据（`altool --list-providers` 直接索取密码）。

→ 结论：**归档签名与上传都需要你在 Xcode 里登录 Apple 账号后，Xcode 自动下载分发证书**。这是 Apple 的账号安全设计，不能绕过。

### 4. 上传到 App Store Connect

**前置：先在 Xcode 登录 Apple 账号**（`Cmd+,` → Accounts → `+` → Apple ID → `sherygril@sina.com`）。
本机当前 `missing Xcode-Username / Xcode-Token`、无 Distribution 证书私钥——登录后 Xcode 会自动补齐。

1. 打开 Organizer：Xcode 菜单 `Window` → `Organizer` → 左侧 `Archives`
2. 找 **Nov 24, 2026** 的 `App`，版本 `1.0 (8)`（即 `App 11-24-26, 5.00 PM.xcarchive`，含 iPad 四方向 + 位置用途描述修复，**这是要上传的最终版**）

3. 选中它 → `Distribute App`
2. 选 `App Store Connect` → `Upload` → `Next`
3. Distribution 选项保持自动签名（Xcode 用刚下载的 Distribution 证书 + Store profile）
4. 勾选 `Include symbols for third-party frameworks`（如出现）

> <details><summary>如果上传失败：常见错误与处理</summary>
>
> - `Invalid credentials in keychain`：回到第 1 步重新登录 Apple ID，或使用 App 专用密码
> - `Missing compliance / ITMS-91053`：在 App Store Connect 的 App 隐私信息里确认 API 用途填完
> - `Upload Symbols Failed`：只影响崩溃日志，不影响审核，可忽略
> - `Invalid Bundle / Unsupported SDK`：Xcode 版本过旧，需升级到支持 iOS 18 SDK 的 Xcode
> </details>
