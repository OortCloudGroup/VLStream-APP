## 九、取证方式与复现（可审计）

- 客户端只读入口（安装版 `/Applications/一键提审.app`）：

```bash
env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS \
  "/Applications/一键提审.app/Contents/MacOS/一键提审" --no-sandbox \
  '--dump-url=https://developer.huawei.com/consumer/cn/hdc-console/index.html#/app/101653523124950145?appId=6917620375647515978&projectId=101653523865493130' \
  '--nav=应用信息|1.0.3 已上架'
```

- 约束：仅允许 `developer.huawei.com`；遍历主文档 + 所有 iframe 读取正文/输入框/链接；`--nav` 用真实鼠标点击左侧菜单**仅用于切换页面**；代码路径不含 fill / save / submit。

- 原始抓包日志：`/tmp/yijian-harmony-dump2.json`（基础信息）、`/tmp/yijian-harmony-pages.json`（应用信息 + 已上架版本页）、`/tmp/yijian-harmony-checked.json`（单选项状态）。
- 关联文档：`docs/华为AGC上架总结.md`（第十五节）、`Android/应用市场上架文案.md`、`iOS/AppStore提交文案.md`、`yijian-tishen/README.md`。
